## 🎯 Objetivo do Projeto
Este software foi desenvolvido para atender às demandas de uma clínica veterinária que realiza consultas e procedimentos cirúrgicos. 

O sistema tem como foco principal facilitar a rotina dos funcionários da clínica, oferecendo uma interface intuitiva e funcionalidades que otimizam o gerenciamento das atividades diárias.

## 🧩 Funcionalidades
- Agendamento de consultas
- Cadastro de pacientes
- Consulta de pacientes já cadastrados
- Visualização de consultas agendadas

---

Este projeto foi criado com o objetivo de integrar conhecimentos práticos e acadêmicos, promovendo uma solução eficaz para o gerenciamento de uma clínica veterinária.
